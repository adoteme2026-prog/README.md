## 📌 Sobre o Projeto

Desenvolvimento de uma plataforma mobile inovadora desenhada para conectar protetores e adotantes de forma inteligente. O projeto utiliza uma abordagem de Engenharia de Software moderna, priorizando a experiência do usuário e a eficiência técnica.

### 🚀 Principais Entregas e Resultados

* **Engenharia de Prompt:** Implementação de técnicas avançadas para orquestração de requisitos e estrutura de interface via plataformas Lovable e Base44.
* **Trabalho em Equipe:** Coordenação técnica e colaboração em um grupo multidisciplinar composto por 7 integrantes.
* **MVP Funcional:** Criação de um protótipo navegável com fluxos validados de login, vitrine de animais e formulário de triagem.
* **Desenvolvimento Assistido por IA:** Utilização de modelos de inteligência artificial para acelerar o ciclo de vida do projeto e garantir regras de negócio robustas.
* **Metodologias Ágeis:** Foco em entregas iterativas, garantindo que a solução atenda às necessidades reais de ONGs e protetores independentes.
